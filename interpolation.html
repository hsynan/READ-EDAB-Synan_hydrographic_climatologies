Interpolation#

Once the data is binned spatiotemporally, cleaned, and aggregated, we can create the climatologies (reference years 2000-2024) using Barnes objective analysis. The code used in the interpolation was translated to python from a package written by Lena Bartell (2016) in Matlab (https://www.mathworks.com/matlabcentral/fileexchange/58937-barnes-interpolation-barnes-objective-analysis)
The interpolation code can be found in EXEC_INTERP.py and the functions required for the interpolation are defined in FUNC_INTERP.py

Step 3: Run interpolation#

You can either download the cleaned, aggreggated point datasets from zenodo or you can run it directly without downloading. In this example, the data is downloaded. The file_path must be the absolute file path, not relative. Additionally, these lines should be run via CLI, rather than in jupyter notebooks.

python EXEC_INTERP.py --depth surface --file_path C:\Users\haley.synan\Documents\synan_hydrographic_climas\AGGREGATED_POINT_SURFACE_2000_2024.csv

  Cell In[2], line 1
    python EXEC_INTERP.py --depth surface --file_path C:\Users\haley.synan\Documents\synan_hydrographic_climas\AGGREGATED_POINT_SURFACE_2000_2024.csv
           ^
SyntaxError: invalid syntax

OR

python EXEC_INTERP.py --depth bottom --file_path C:\Users\haley.synan\Documents\synan_hydrographic_climas\AGGREGATED_POINT_BOTTOM_2000_2024.csv

The output climatologies will either be downloaded to the same directory as the point data, or to the current directory.
